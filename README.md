Цель: Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.
  
Задание: Оформить страницу из ЛР №1 с помощью внешнего CSS файла (style.css). 
Реализовать:
  - Основной стиль – во внешнем файле; 1 элемент с inline стилями; 1 правило во внутреннем блоке <style>.
  - CSS переменные в :root для цветов и шрифтов.
  - Примеры позиционирования: static, relative, absolute.
  - Состояния элементов: :hover, :active, :focus, :visited.
  - Контрастность текста не менее 4.5:1.
  
Тема «Учёный и исследователь» (эффект «лабораторного стекла») Примените эффект «матового стекла» (backdrop-filter: blur) к блоку <aside>. При :hover на карточках проектов добавляйте свечение изнутри. 
При :active меняйте прозрачность карточки. 
В переменных: основной – светло-голубой, акцент – тёмно-синий. 
Inline-стиль: opacity: 0.9 для формы. 
Внутренний блок: стили для заголовков (тень и цвет).
